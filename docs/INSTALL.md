# Установка, обновление и удаление

## Что нужно

- 64-битная Windows 10/11.
- Steam-версия **The Witcher: Enhanced Edition** (проверено на 1.4.5.1304).
- Xbox-совместимый контроллер (XInput). Мод читает слот 0.
- Права на запись в папку игры. Steam не должен обновлять игру во время установки.
- Для сборки контроллера из исходников и для работы `Setup.exe` — .NET Framework 4. В Windows 10/11 обычно уже установлен.

## Установка через Setup.exe

Скачай `WitcherDirectCombatSetup.exe` из [Releases](https://github.com/Ford-100500/witcher-direct-combat/releases/latest) или возьми из архива `WitcherDirectCombat-Setup-0.3.0.zip`.

1. Закрой игру полностью.
2. Запусти `WitcherDirectCombatSetup.exe`.
3. Проверь папку игры. Если путь не определился, нажми «Обзор...» и выбери папку `The Witcher Enhanced Edition` (внутри должен быть `System\witcher.exe`).
4. Оставь галочку **«Создать ярлык на рабочем столе»**.
5. Нажми **«Установить»**.

Установщик кладёт те же файлы, что и `Install.cmd`: контроллер, `Play.cmd`, `installed.json` и `testtools.lua`. Если в игре был другой `testtools.lua`, он сохраняется как `testtools.lua.wdc-backup`.

Собрать установщик самому: `installer\Build.ps1`.

## Установка через Install.cmd

1. Закрой «Ведьмака» полностью: не только главное меню, а процесс `witcher.exe`.
2. Скачай репозиторий ZIP-архивом с GitHub или склонируй его. Распакуй в любую постоянную папку — она понадобится для удаления.
3. Запусти `Install.cmd`.
4. На вопрос о папке игры:
   - `P` — вставить полный путь к папке `The Witcher Enhanced Edition`;
   - `S` — поиск по типичным библиотекам Steam.
   Установщик проверит, что внутри есть `System\witcher.exe`, и попросит подтвердить папку.
5. Выбери способ установки контроллера:
   - `U` — готовая сборка `Payload\DirectCombatController.exe` (по умолчанию);
   - `C` — собрать из `Payload\DirectCombatController.cs` на этом компьютере.
6. Дождись сообщения `Installed Witcher Direct Combat to ...`.

Установщик кладёт в игру:

| Что | Куда |
| --- | --- |
| Контроллер | `DirectCombat\DirectCombatController.exe` |
| Лаунчер | `DirectCombat\Play.cmd` |
| Манифест хешей | `DirectCombat\installed.json` |
| Lua-хук | `System\Scripts\testtools.lua` |
| Путь к игре | `location.txt` рядом с `Install.cmd` |

Сохранения и `witcher.exe` не меняются. Если в игре уже лежит чужой `testtools.lua`, `Install.cmd` откажется его перезаписывать, а `Setup.exe` сохранит его как `testtools.lua.wdc-backup`.

## Запуск

- Дважды щёлкни `DirectCombat\Play.cmd` в папке игры.
- `Setup.exe` создаёт ярлык **«The Witcher - Direct Combat»** на рабочем столе; он делает то же самое.
- Или сделай ярлык вручную: правый клик по `Play.cmd` → «Отправить» → «Рабочий стол». Иконку можно взять из `System\witcher.exe`.
- `Play.cmd` запускает контроллер и открывает игру через Steam (`steam://rungameid/20900`).
- Steam показывает меню из трёх вариантов запуска. Выбери **Play The Witcher** (первый). Мод ждёт игру до 30 минут, так что спешить с выбором не нужно.
- Игра запускается только через Steam. Прямой запуск `System\witcher.exe` в Steam-версии сразу закрывается — это не ошибка мода.

## Проверка

1. В диспетчере задач есть `DirectCombatController.exe`.
2. Окно игры в фокусе — контроллер сам включает F3-камеру.
3. В игре работает левый стик, правый стик и кнопки.
4. После запуска игры в `System\direct_combat_perfect_combo.log` появляется запись:

```
perfect combo settings: true nil
old mechanics: true
combat time advance: 10
```

Если лог есть, Lua-часть мода применилась. Если контроллер не реагирует — проверь, что окно игры активно и контроллер подключён.

## Привязка «следующее оружие»

Чтобы D-pad ← пропускал пустые слоты, контроллер на время работы назначает действию игры «следующее оружие» клавишу `K`. Исходное значение сохраняется в `DirectCombat\nextweapon.bak` и возвращается при штатном выходе контроллера, а также при удалении мода.

Если игра уже запущена до старта контроллера и привязка ещё не `K`, новая привязка не подхватывается. В этом случае D-pad ← перебирает слоты напрямую (`Q`, `E`, `R`, `T`, `U`), и пустые слоты не пропускаются. Для правильной работы запускай игру через `Play.cmd`.

## Обновление

1. Закрой игру.
2. Запусти `Install.cmd` из новой версии репозитория и укажи ту же папку.
3. Установщик заменит контроллер, `Play.cmd` и манифест. `testtools.lua` заменится, только если он совпадает с прошлой версией мода.

Старый контроллер должен быть закрыт — установщик это проверяет.

## Удаление

1. Запусти `Uninstall.cmd` из папки репозитория.
2. Он возьмёт путь из `location.txt`, дождётся закрытия игры, остановит контроллер и удалит только те файлы, чьи хеши совпадают с `installed.json`.
3. Если файл меняли вручную, он останется на месте — установщик не трогает чужие изменения.

`Uninstall.cmd` можно запустить и с явным путём: `Uninstall.ps1 -GameDir "E:\...\The Witcher Enhanced Edition"`.

Если мод ставился через `Setup.exe`, используй `Uninstall.cmd` из архива с установщиком или тот же `Uninstall.ps1 -GameDir "путь к игре"`. Манифест `installed.json` создаётся обоими способами.

При удалении восстанавливается `testtools.lua.wdc-backup`, если он есть, и удаляется ярлык «The Witcher - Direct Combat» с рабочего стола.

## Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| Игра закрывается сразу после запуска | Запускай через Steam / `Play.cmd`, а не `witcher.exe` напрямую |
| Steam спрашивает вариант запуска | Выбери **Play The Witcher** |
| Контроллер не реагирует | Окно игры должно быть в фокусе; контроллер — в слоте 0; перезапусти `Play.cmd` |
| D-pad ← не пропускает пустые слоты | Игра должна быть запущена после контроллера, через `Play.cmd`; иначе работает резервный перебор `Q`/`E`/`R`/`T`/`U`. Перезапусти игру через `Play.cmd`. |
| Steam проверил целостность или обновил игру | `testtools.lua` вернулся к оригиналу, Lua-часть отключена. Переустанови мод через `Install.cmd`. |
| Контроллер не виден, хотя геймпад подключён | Отключи Steam Input для игры: он может скрыть физический геймпад от XInput |
| Принудительно закрыл контроллер, залипли клавиши | Запусти `Play.cmd`: при старте мод сбрасывает Alt, W/A/S/D, ЛКМ и ПКМ |
| Не подсвечиваются объекты | Alt на RB или фиксация на RS; проверь, что мод видит окно игры |
| Свернул игру с включённой фиксацией Alt | Alt отпускается сам при потере фокуса; если нет — нажми и отпусти Alt на клавиатуре |
| Alt «залип» после убийства процесса | Нажми и отпусти Alt на клавиатуре; следующий запуск `Play.cmd` тоже сбросит состояние |
| Антивирус ругается на контроллер | `DirectCombatController.exe` не подписан; собери его из исходников (вариант `C`) или добавь в исключения |
| Установщик пишет про другой `testtools.lua` | В игре уже стоит чужой мод с этим файлом; верни оригинал или переименуй файл |
| Установщик просит закрыть игру/контроллер | Заверши `witcher.exe` и `DirectCombatController.exe` |
| Нет геймпада | Нужен XInput-контроллер; DualShock/DualSense подключай через эмуляцию XInput |

Полный список известных проблем — в [KNOWN-ISSUES.md](KNOWN-ISSUES.md).

## Конфликты с другими модами

Мод занимает `System\Scripts\testtools.lua`. Другие моды, которые пишут в этот же файл, конфликтуют с ним. Остальные файлы игры не меняются, поэтому моды на текстуры, озвучку и сохранения обычно совместимы.
