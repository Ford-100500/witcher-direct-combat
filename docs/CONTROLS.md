# Карта управления

Раскладка рассчитана на Xbox-совместимый контроллер (XInput, слот 0) и русскую или английскую версию игры. Мод работает, пока окно «Ведьмака» в фокусе.

## Бой

| Кнопка | Действие |
| --- | --- |
| Левый стик | Движение (W/A/S/D) |
| Правый стик | Камера и курсор |
| A | Взаимодействие и ЛКМ: короткое нажатие — клик, удержание — перетаскивание предметов. При достатом мече и враге под курсором — клик-удар |
| X | Удар выбранным стилем. На старте выбран силовой |
| Y | Быстрые слоты зелий и бомб (см. ниже) |
| B + левый стик | Уклонение в сторону стика |
| LB | Убрать меч в ножны (`Tab`). Достать меч можно только выбором оружия на D-pad ← |
| RB | Alt, пока кнопка зажата: подсветка названий объектов и NPC |
| RT | Удерживать и отпустить — сотворить выбранный знак |
| D-pad ↑ | Сменить стиль: сильный → групповой → быстрый |
| D-pad ← | Сменить оружие: сталь → серебро → доп. оружие |
| D-pad → | Сменить знак: Аард → Квен → Ирден → Игни → Аксий |
| D-pad ↓ | Открыть инвентарь (`I`) |
| Menu (☰) | Esc: меню игры, сохранение, выход |
| View / Back | Пауза боя (`Space`) |
| LT | Свободна, зарезервирована под радиальное меню |

## Интерфейс и меню

- Правый стик двигает курсор мыши, A держит левую кнопку мыши. Короткое нажатие — клик, удержание — перетаскивание. Этого достаточно, чтобы ходить по меню, инвентарю и диалогам.
- **Menu** открывает и закрывает меню игры (`Esc`). Через него же сохраняется игра.
- **View / Back** ставит и снимает паузу боя (`Space`), не открывая меню.
- **D-pad ↓** открывает инвентарь. Переключение вкладок (инвентарь, персонаж, карта, журнал, алхимия) пока не разложено по кнопкам — это следующий этап.

## Стили, оружие и знаки

- Стиль, оружие и знак меняются по кругу одним нажатием D-pad. Текущий выбор видно на HUD игры.
- Стиль, выбранный D-pad ↑, использует X. Стартовый стиль — силовой.
- Смена стиля может автоматически достать меч: игра реагирует на клавишу стиля.
- Смена оружия достаёт выбранное оружие. Убрать меч можно отдельно — LB.
- Знак колдует RT: удерживай, чтобы прицелиться, отпусти, чтобы сотворить. RB больше не колдует — он занят Alt.

## Быстрые слоты (Y)

Одно нажатие Y использует слот `6`, два быстрых нажатия — `7`, три — `8`. Мод ждёт 0,4 секунды после последнего нажатия, затем отправляет клавишу. Поэтому одиночное использование срабатывает с небольшой задержкой.

Клавиши `6/7/8` в игре — это `Elixir1/2/3` (`UseQuickSlot`). Слот хранит один предмет, пока он не потратится; поэтому слот выбирается количеством нажатий, а не прокруткой.

## Alt и подсветка

Alt в игре подсвечивает названия предметов и NPC.

- **RB** держит Alt, пока кнопка зажата. Можно держать сколько угодно.
- **RS (нажатие правого стика)** включает фиксацию Alt: первое нажатие зажимает Alt, второе отпускает.
- Alt отпускается автоматически, когда окно игры теряет фокус, игра закрывается, геймпад отключается или контроллер завершается. Сворачивать игру с включённой фиксацией безопасно.
- При старте контроллер сбрасывает Alt, оставшийся от прошлого аварийного завершения.
- Windows забирает `Alt+Tab`, `Alt+Esc` и `Alt+Space`. Мод отпускает Alt на время LB (`Tab`), Menu (`Esc`) и Back (`Space`), чтобы не переключать окна. Остальные сочетания лучше не провоцировать.
- Если процесс контроллера убить принудительно, Alt может остаться зажатым. Нажми и отпусти Alt на клавиатуре или перезапусти `Play.cmd`.

## Установка и запуск

Мод ставится в папку игры и запускается через `DirectCombat\Play.cmd`: он поднимает контроллер и открывает игру через Steam. Подробности — в [INSTALL.md](INSTALL.md).
