# Witcher Direct Combat — форк с переработанным управлением

Геймпадный мод для **The Witcher: Enhanced Edition** (Steam, версия игры 1.4.5.1304). Расширяет окно комбо и даёт полноценное управление Xbox-контроллером: движение, камера, стили боя, оружие, знаки, зелья, карта, меню и подсветка объектов.

> Это форк проекта [Witcher Direct Combat](https://github.com/VeggieVampire/witcher-direct-combat).
> Оригинальный мод и его код написал **Nick Farrow** (GitHub: **VeggieVampire**).
> Оригинал распространяется по лицензии MIT; она сохранена в этом репозитории.
> **Статус:** экспериментальный форк. У мода есть известные ограничения и хрупкие места; полный список — в [docs/KNOWN-ISSUES.md](docs/KNOWN-ISSUES.md).

## Что делает мод

- Расширяет окно тайминга мечевого комбо, чтобы можно было жать атаку не глядя на «пламенный» курсор.
- Читает XInput и отправляет игре её собственные клавиши и клики мыши.
- Работает только когда окно «Ведьмака» в фокусе, поэтому не мешает другим приложениям.
- Не меняет сохранения и `witcher.exe`. Установка обратима.

Игра при этом остаётся обычным «Ведьмаком»: цели выбираются курсором, удары и парирования считает оригинальный движок.

## Что изменено в этом форке

- Игра запускается **через Steam** (`steam://rungameid/20900`), а не напрямую. Прямой запуск `witcher.exe` в Steam-версии сразу закрывается.
- Мод понимает русское окно `Ведьмак (...)` — раньше он ждал только `The Witcher (...)` и выключался.
- Контроллер ждёт игру до 30 минут: Steam показывает меню из трёх вариантов запуска, и выбор может занять время.
- Переработана раскладка: D-pad для стилей, оружия, знаков и инвентаря; LB — ножны; LS — карта; RB/RS — Alt; Menu/Back поменяны местами.
- D-pad ← вызывает штатное «следующее оружие» игры, поэтому пустые слоты пропускаются. На время работы мод привязывает это действие к `K`, исходная привязка лежит в `DirectCombat\nextweapon.bak`. Работает только если игра запущена после контроллера, через `Play.cmd`; иначе D-pad ← перебирает `Q`/`E`/`R`/`T`/`U` напрямую, и пустые слоты не пропускаются.
- Y использует быстрые слоты зелий и бомб по количеству нажатий.
- A удерживает левую кнопку мыши: короткое нажатие — клик, удержание — перетаскивание предметов в инвентаре.
- Alt можно держать сколько нужно: RB держит его, RS включает и выключает фиксацию.
- Добавлен GUI-установщик с галочкой ярлыка на рабочем столе. Исходник и сборка — в `installer/`; готовый EXE не публикуется.

## Управление

Полная карта со всеми оговорками — в [docs/CONTROLS.md](docs/CONTROLS.md). Известные проблемы и хрупкие места — в [docs/KNOWN-ISSUES.md](docs/KNOWN-ISSUES.md).

| Кнопка | Действие |
| --- | --- |
| Левый стик | Движение |
| Нажатие LS | Карта (`M`) |
| Правый стик | Камера |
| Нажатие RS | Включить/выключить фиксацию Alt |
| A | Взаимодействие и ЛКМ: короткое нажатие — клик, удержание — перетаскивание |
| X | Удар выбранным стилем (старт — силовой) |
| Y | Быстрые слоты: 1 нажатие — 6, 2 — 7, 3 — 8 |
| B + стик | Уклонение в сторону стика |
| LB | Убрать меч в ножны (`Tab`). Достаётся меч выбором оружия на D-pad ← |
| RB | Alt, пока кнопка зажата (подсветка объектов и NPC) |
| RT | Удерживать и отпустить — знак |
| D-pad ↑ | Инвентарь (`I`) |
| D-pad ← | Следующее оружие: игра сама пропускает пустые слоты |
| D-pad → | Стиль: сильный → групповой → быстрый |
| D-pad ↓ | Знак: Аард → Квен → Ирден → Игни → Аксий |
| Menu (☰) | Esc — меню игры, там сохранение |
| View / Back | Пауза боя (`Space`) |

LT сейчас свободна — оставлена под будущее радиальное меню.

## Требования

- 64-битная Windows.
- Steam-версия The Witcher: Enhanced Edition.
- Xbox-совместимый контроллер (XInput), слот 0.
- .NET Framework 4 — для сборки контроллера из исходников. Готовая сборка уже лежит в `Payload`.

## Установка

Подробный гайд с проверкой и удалением — в [docs/INSTALL.md](docs/INSTALL.md).

### Вариант 1. Setup.exe (передаётся отдельно)

Если у тебя есть `WitcherDirectCombatSetup.exe`:

1. Закрой игру полностью.
2. Запусти установщик, проверь папку игры.
3. Оставь галочку **«Создать ярлык на рабочем столе»**.
4. Нажми **«Установить»**.
5. Запускай игру с ярлыка или через `DirectCombat\Play.cmd`; в Steam выбери **Play The Witcher**.

Готовый EXE **не публикуется** в репозитории и релизах. Собрать самому: `installer\Build.ps1` → `dist\WitcherDirectCombatSetup.exe`.

### Вариант 2. Install.cmd из репозитория

1. Закрой игру полностью.
2. Запусти `Install.cmd`.
3. Укажи папку игры (вставить путь или найти автоматически) и выбери `U` — готовая сборка контроллера.
4. Запускай игру через `DirectCombat\Play.cmd` (или ярлык на него).
5. В меню Steam выбери **Play The Witcher**.

`Play.cmd` сам поднимает контроллер и открывает игру через Steam. Мод включится, когда окно игры станет активным.

## Как это работает

`DirectCombatController.exe` опрашивает XInput и отправляет игре клавиши и движения мыши, пока окно игры в фокусе. Окно определяется по процессу `witcher.exe`, поэтому локализованные заголовки не мешают.

`System\Scripts\testtools.lua` выполняется при старте игры и задаёт:

```lua
g_cAuroraSettings.m_bUseOldAttackMechanics = true
g_cAuroraSettings.m_fCombatTimeAdvance = 10.0
```

Это и расширяет окно комбо. Исходники: `Payload/DirectCombatController.cs` и `Payload/testtools.lua`.

## Честно об ограничениях

Мод не идеальный. Полный список — в [docs/KNOWN-ISSUES.md](docs/KNOWN-ISSUES.md). Главное:

- **Оружие.** Мод не видит инвентарь. D-pad ← нажимает `K`, а игра сама выбирает следующее оружие. Работает только если игра запущена после контроллера, через `Play.cmd`. Если игра уже была запущена, D-pad ← перебирает `Q`/`E`/`R`/`T`/`U` напрямую, и пустые слоты не пропускаются.
- **Привязка `K`.** На время работы мод меняет «Следующее оружие» на `K`; исходное значение — в `nextweapon.bak`. Принудительное убийство контроллера может оставить `K`; следующий запуск или удаление восстановит.
- **Клавиши по умолчанию.** Стили (`Z`/`X`/`C`), знаки (`1`–`5`), карта (`M`), инвентарь (`I`) и зелья (`6`/`7`/`8`) зашиты. Переназначение в игре ломает соответствующую кнопку мода.
- **testtools.lua.** Мод заменяет `System\Scripts\testtools.lua`. Проверка целостности Steam или обновление игры вернёт оригинал и отключит Lua-часть (окно комбо); переустанови мод.
- **Другие моды.** Конфликт с модами, которые используют `testtools.lua` или те же клавиши.
- **Инвентарь.** Курсор — правый стик; левый стик отправляет WASD. Вкладки и прокрутка колёсиком не назначены. A держит ЛКМ и может ударить, если под курсором враг.
- **Y.** Окно 0,4 с; 1/2/3 нажатия; 4+ — слот 8. Слот хранит предмет, пока он не потратится; пустой слот ничего не делает.
- **Стили и знаки.** Мод ведёт свои индексы; смена через клавиатуру или UI может их разсинхронизировать. Стартовый стиль — силовой.
- **Alt.** Авто-отпускание при потере фокуса и выходе; принудительное убийство может залипить Alt/клавиши до следующего запуска.
- **Запуск.** Только Steam-версия 1.4.5.1304, контроллер в слоте 0, запуск через `Play.cmd`. Steam Input может скрыть геймпад; оверлеи перехватывают ввод.
- **Сессия и подпись.** Ожидание игры до 30 минут, сессия до 24 часов; `DirectCombatController.exe` не подписан.

## Планы

- Нативное радиальное меню на удержание LT: пауза, выбор левым стиком (зелья, бомбы, знаки, оружие и стиль).
- Управление инвентарём и переключение вкладок (инвентарь, персонаж, карта, журнал, алхимия).
- Доработка быстрых слотов, если понадобится выбор без счётчика нажатий.
